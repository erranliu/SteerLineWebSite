# 中英文术语表

| English | 中文 | 用法 |
| --- | --- | --- |
| specification (Spec) | 规格（Spec） | 需求、预期行为、约束及验收标准的描述 |
| roadmap | Roadmap | 连接项目目标与计划工作的规划；产品概念保留英文 |
| directed acyclic graph (DAG) | 有向无环图（DAG） | 表达不存在循环路径的依赖关系 |
| Git worktree | Git worktree | Git 仓库的独立工作目录 |
| task | 任务 | 边界明确的工作单元 |
| review | 审查 | 对计划或结果进行检查和判断 |
| verification | 验证 | 通过证据检查结果是否满足要求 |
